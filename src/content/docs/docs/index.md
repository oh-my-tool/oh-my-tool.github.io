Oh My Tool is an extensible, local-first runtime for AI agents. It gives agents
one consistent way to discover and execute tools from native extensions and
MCP providers.

## The core loop

```text
ohmytool search → ohmytool describe → ohmytool run
```

Start with the [installation guide](/docs/getting-started/installation/), then
run your first tool in [First Run](/docs/getting-started/first-run/).
