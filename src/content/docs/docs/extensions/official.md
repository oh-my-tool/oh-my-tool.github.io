Official extensions stay independent from the core runtime while sharing the
same SDK contract.

## MySQL

[omt-mysql](https://github.com/oh-my-tool/omt-mysql) provides native tools for
querying and operating MySQL connections.

```powershell
ohmytool extension install @oh-my-tool/mysql
```

## Redis

[omt-redis](https://github.com/oh-my-tool/omt-redis) brings Redis capabilities
into the local runtime.

```powershell
ohmytool extension install @oh-my-tool/redis
```

## Kafka

[omt-kafka](https://github.com/oh-my-tool/omt-kafka) provides event-streaming
capabilities through the same extension boundary.

Provider-specific configuration and release notes live in each extension's
repository.
