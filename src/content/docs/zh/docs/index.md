Oh My Tool 是一个可扩展、本地优先的 AI Agent 工具运行时。它让 Agent
可以用统一方式发现并执行来自原生扩展和 MCP Provider 的工具。

## 核心循环

```text
ohmytool search → ohmytool describe → ohmytool run
```

从[安装指南](/zh/docs/getting-started/installation/)开始，然后在[第一次执行](/zh/docs/getting-started/first-run/)中运行你的第一个工具。
